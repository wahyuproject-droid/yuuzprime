PIPELINE OPTIMASI

Pemutaran adaptif tanpa lag dengan disk cache mandiri.

YuuZPrime memanfaatkan arsitektur streaming HLS dengan initial pre-buffer 800ms. Sistem membaca segmen chunk secara asinkron sehingga transisi resolusi terjadi tanpa freeze atau audio desync.

  • Buffer awal teroptimasi: 800ms (Standar industri: 3000ms+)
  • Mode Caching: Force-Cache Native Disk
  • Dukungan Video: H.264, HEVC (H.265), VP9, AV1
  • Dekoder Audio: AAC, AC-3, E-AC-3, Opus
player-engine-config.json HLS_V2 
{
  "engine": "NativeMediaPipeline",
  "buffer": {
    "initialPlaybackBufferMs": 800,
    "minBufferMs": 5000,
    "maxBufferMs": 30000,
    "bufferForPlaybackAfterRebufferMs": 2000
  },
  "cachingStrategy": "DIRECT_DISK_FORCE_CACHE",
  "hardwareAcceleration": true,
  "zeroTrackers": true
}
64-BIT SOLE TARGET

Dikeluarkan khusus untuk efisiensi CPU modern.

Dengan meninggalkan overhead kompatibilitas 32-bit usang, YuuZPrime mengkompilasi instruksi register 64-bit langsung ke chipset smartphone Android masa kini. Penggunaan baterai lebih hemat dan rendering UI stabil 60–120 FPS.

  • ABI Target: ARM64-v8a (64-Bit murni)
  • Kompatibilitas OS: Android 9.0 (Pie) hingga Android 15
  • Konsumsi RAM saat memutar: ~85 MB hingga 140 MB
  • Ukuran instalasi paket: Hanya ~28 MB
build.gradle.kts (Native target) ARM64 
ndk {
    abiFilters.clear()
    abiFilters.add("arm64-v8a")
}

packagingOptions {
    resources.excludes += "**/32bit_legacy/**"
    jniLibs.useLegacyPackaging = false
}
FLEKSIBILITAS LENGKAP

Subtitle kustom dan integrasi provider modular.

Tidak lagi terkunci pada satu format subtitle atau satu penyedia. YuuZPrime memungkinkan Anda mengimpor file subtitle lokal (.srt, .vtt, .ass), mengatur ukuran font, warna latar, dan penundaan waktu per milidetik.

  • Format Subtitle: SubRip (.srt), WebVTT (.vtt), ASS/SSA
  • Pengaturan Waktu: Mundurkan/Majukan dalam rentang 100ms
  • Dukungan Sumber Kustom: Integrasi API Provider mandiri
  • Ekspor/Impor Bookmark dan Watchlist via JSON
custom-provider-sample.js MODULAR 
export async function resolveStream(movieId) {
  const sources = await fetchMeta(movieId);
  return {
    streams: sources.map(s => ({
      quality: s.res, // "1080p", "4K"
      url: s.m3u8Url,
      subtitles: s.tracks
    }))
  };
}

PERTANYAAN UMUM

Pertanyaan yang sering diajukan.

Temukan jawaban seputar instalasi, kompatibilitas, dan keamanan aplikasi.

HP apa saja yang kompatibel dengan versi ARM64-v8a?

Hampir seluruh smartphone Android modern keluaran tahun 2017 ke atas (Samsung, Xiaomi, Poco, Oppo, Vivo, Realme, Infinix, Google Pixel, OnePlus, dll.) menggunakan chipset 64-bit (ARM64-v8a) dengan OS Android 9 atau lebih baru.

Apakah YuuZPrime benar-benar gratis dan bebas iklan?

Ya, YuuZPrime dibangun sebagai proyek open-source tanpa modul monetisasi iklan pihak ketiga, tanpa pelacak analitik invasif, dan tanpa biaya langganan apapun.

Mengapa muncul peringatan "Install Unknown Apps" saat memasang APK?

Ini adalah prosedur standar keamanan Android untuk aplikasi apapun yang diunduh di luar Google Play Store. Berkas APK YuuZPrime ditandatangani secara digital (digitally signed) dan bebas dari malware berbahaya. Cukup pilih "Izinkan dari sumber ini" untuk melanjutkan.

Bagaimana cara memperbarui ke versi baru di masa mendatang?

YuuZPrime memiliki fitur In-App APK Updater. Saat rilis baru tersedia di GitHub, aplikasi akan menampilkan jendela dialog pembaruan dengan progress bar unduhan langsung di layar Anda.

Apakah bisa memutar video menggunakan aplikasi pemutar eksternal?

Sangat bisa! Di halaman pemutar, Anda dapat memilih tombol "Buka di Pemutar Eksternal" untuk meneruskan tautan video ke aplikasi favorit Anda seperti VLC for Android, MPV, MX Player, atau Nova Video Player.
